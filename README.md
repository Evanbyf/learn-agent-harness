# learn Agent Harness —— Evan

一份面向产品经理的 **Agent Harness** 学习笔记：从最小的 Agent Loop 出发，一个模块一个模块地拆解一个“类 Claude Code / Cowork”的 Agent 是怎么搭起来的。

> 核心心法：**自主性来自模型，Harness 负责把模型放进一个能感知、能行动、能记住、靠得住的环境里。**
> Agent = 模型 + Harness。

主线代码参照：[shareAI-lab/learn-claude-code](https://github.com/shareAI-lab/learn-claude-code)。

## ⭐ 先看这份演示稿：Agent 从零到一

**[slides/Agent从零到一_分享.html](slides/Agent从零到一_分享.html)** —— 整套笔记的总括版，约 60 分钟的内部分享稿，也是最容易入门的一份。

用一个比喻贯穿全程：模型是一位**只有当次记忆的博士生**，关在门里，每次只能收一叠纸、回一张纸条（一次输入，一次输出）。Harness 就是门外的那套机制。案例用 IM 办公协同 Agent「小贴心」（会议、文档、群消息）。

## 怎么读

0. 先过一遍上面的**演示稿**，建立全局印象。
1. 再读 **00 总纲**，了解路线和两个验收目标（能看懂 harness 代码、能画出端到端全景图）。
2. 按编号顺序读 01 → 12，模块之间有依赖。
3. 每篇都有“自测题”和“追问与深挖”，建议先自答再看参考答案。
4. 最后读两篇附录。
